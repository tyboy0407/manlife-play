# ManLife

休閒閒置經營原型(Godot 4.7、GDScript、3D 方塊占位):雪地漁市。開發約定見 `CLAUDE.md`。

## 在 iPhone 上玩(PWA)

- 網址:https://tyboy0407.github.io/manlife-play/ 。用 Safari 開,第一次會下載約 55 MB(之後離線快取),等「ManLife」畫面跑完就能玩。
- 加到主畫面:Safari 下方「分享」→「加入主畫面」,之後像 App 一樣全螢幕直式開啟;存檔在手機瀏覽器的儲存空間。
- 操作:手指按住畫面任何地方拖動就會走(浮動搖桿),放開就停;右上角「選單」可以開關提示箭頭、音效、畫質(流暢 / 精細)、FPS 顯示、重新開始(要按兩次)。
- 畫質:手機預設「流暢」(沒有即時陰影,改用腳下圓影,3D 以 0.75 倍解析度算);覺得手機夠力可以切「精細」。開 FPS 顯示就能比較兩種模式的幀數。
- 更新:改完程式後在電腦執行 `python tools/deploy_web.py`(匯出 + 推到 GitHub Pages,約一分鐘生效),手機上的 App 重開一次就會換新版。
- 本機預覽:`python tools/deploy_web.py --export-only` 再 `python tools/serve_web.py --port 8090`,終端機會印出 iPhone 同一個 Wi-Fi 可開的網址。

## 在電腦上開發

- 用 Godot 4.7 開啟本資料夾,按 F5 進入星港漁市(`game/levels/harbor.tscn`);桌機視窗是直式 450 × 800,滑鼠拖也能當搖桿。
- 操作:WASD / 方向鍵 / 手把左搖桿移動;H 開關提示箭頭;F9 刪存檔重新開始。所有互動都是站到格子上自動進行。
- 引導:新遊戲有七步教學(抓魚 → 切 → 拿 → 上架 → 收銀 → 收錢 → 買第一樣東西),頭上的小箭頭指方向、目標上方有彈跳的大箭頭,畫面上方寫目標;教學完成後箭頭繼續提示當下最該做的事(H 可關)。
- 基本循環:走進上方淺水區碰到魚就抓(疊在背上,8 條滿)→ 站到切魚台上方「放這裡」格卸貨 → 工人切成魚片 → 站到下方「從這裡拿」格取魚片
  → 走到櫃台左邊「上架」格 → 站到櫃台下方「收銀」格,排隊的顧客才會買(每件 $2),錢堆在錢格 → 站到錢格把錢收進錢包(左上角顯示,不佔背包)
  → 站在價格牌上停一下就開始從錢包付錢(帶著錢走過不會付;可分期、走開暫停)。
- 價格牌(中間一排,左到右):僱用漁夫 $10(可僱 3 人,越買越貴)、僱用搬運工 $30(把成品搬到櫃台 / 下游工作站,2 人)、僱用收銀員 $20(站櫃台收銀,2 人)、
  擴充背包 $25(3 次)、工人速度 $20(3 級)、堆疊上限 $20(3 級)。橘色建地:第二座切魚台 $50、烤魚攤 $60(魚片 -> 烤魚,烤魚櫃台每件 $5)。
- 右下角垃圾桶:站上去把背上的貨物全部丟掉(錢在錢包裡,不受影響)。
- 存檔:每 10 秒、每次買完、關視窗自動存到 `user://manlife_save.json`;下次開啟接著玩。
- 模型:`assets/models/game/`(Kenney Mini Characters 人物、Survival Kit 的魚、Quaternius 動畫魚,全部 CC0,來源見裡面的 CREDITS.md);
  哪個角色用哪個人物在 `data/config/game.json` 的 `models`,物品模型在 `data/items.json` 的 `model`;原始套件放 `assets/models/<套件名>/`(有 .gdignore,git 不追蹤)。
  魚片 / 烤魚還是方塊,候選模型清單見 `docs/model_candidates.md`。
- 北極熊:村裡有幫手後會不定時從地圖邊緣進來吃掉漁夫 / 收銀員 / 搬運工(被吃就永久消失、僱用牌不退),
  玩家要穿過西邊柵欄缺口到村外武器店買武器(三級:趕跑 / 趕跑後更久不來 / 看到就逃),帶著武器靠近熊就會把牠趕跑。
  數值在 `data/config/game.json` 的 `bear` 與 `weapon`;熊目前是白色方塊占位(`models.bear.file` 填模型路徑就會換)。
  第一群熊 3 分鐘後才來;熊會成群(一次 1 ~ 4 隻),咬 8 秒吃掉一個幫手、一群最多吃 2 個就撤退,吃過的熊不會自己走,要打跑牠。被吃掉的幫手可以在原本的牌子用 1.5 倍價格買回。熊有血條:帶著武器靠近會自動攻擊(每 0.5 秒一下),
  打到歸零牠才逃;武器升級只加攻擊力(10 / 20 / 35)。遊戲時間越久熊血越厚、3 分鐘後來得越來越密(最快 30 ~ 40 秒一群);
  8 分鐘出北極熊王:連水裡的魚也吃,每吃一口變大(不回血);牠還會拆建築:咬切魚台 / 烤魚攤 / 守衛塔滿 10 秒就拆成廢墟,
  站到廢墟上花 $100 修好(`data/shop.json` 的 `repairStation`)。打死後 5 分鐘再來。
- 掉落物:打跑的北極熊掉一張毛皮、打死的王掉一顆熊王牙,走過去就撿(不佔背包,HUD 有數量)。毛皮拿到村外武器店旁的「升級武器店」牌
  (3 / 8 / 15 張,三級),每升一級武器牌多賣一級更強的武器(Lv4 ~ 6:攻擊力 55 / 80 / 120,鎬子模型)。熊王牙站到完好的守衛塔底下付 1 顆,
  塔變成強力守衛塔:血 2000(扛 50 口)、每箭 25(`tower.strong`)。
- 擴建村莊:存到 $1000 站上東牆前的「擴建村莊」牌,整面東牆拆掉,往東多一塊地(第二個水區、切魚台、烤魚攤、兩座櫃台,顧客也變多),
  僱用牌也多開放名額(搬運工 +4、收銀員 +2、漁夫 +2)。顧客一次要 1 ~ 5 件(`customers.wantWeights`)。
  擴建區裡會出現「再擴建村莊」牌:第二次 $2000(再一塊地:第三個水區、切魚台 + 三座烤魚攤、兩座櫃台),第三次 $8000(第四個水區、兩座烤魚攤、
  服飾店 + 毛衣櫃台);每次僱用名額再開一輪、每塊地也有自己的六座守衛塔。
- 服飾店:站在服飾店的輸入格把北極熊毛皮放進去(站 0.8 秒才開始放,走過不會掉),工人 5 張毛皮做一件毛衣,毛衣送到毛衣櫃台一件賣 $200(顧客一次買一件)。
- 搬運工:哪裡最缺貨先補哪裡;烤魚攤的魚片原料區空了最優先,先讓烤魚攤開工。「搬運工容量」牌(切魚台西側)三級每級 +4,現有的搬運工也馬上變大。
- 捕熊夾 / 誘餌:每塊地北邊水區兩側各有一個捕熊夾位($40,熊踩到扣 60 血、定住 3 秒,用掉後站回原位再買)、西側水邊一個誘餌位
  ($30,8 格內的熊會先去吃魚堆、吃 10 秒,正好讓守衛塔射、自己打)。
- 傳送帶:每座工作站旁有一塊「傳送帶」牌($150,兩端都蓋好才出現),買了成品就自己坐帶子到同種貨的櫃台(每秒一件,櫃台滿了在末端排隊),
  搬運工就能專心把魚片送去烤魚攤。
- 守衛塔:村莊四個角落、以及村中央水邊(切魚台之間)各有一塊 $200 的地基牌,共六座(每塊擴建區也照同樣位置再六座,擴建後才出現),付清就蓋起守衛塔,塔頂守衛會朝靠近的北極熊射箭;熊靠近或被射中會來拆塔,
  血 800(一般熊咬一口 40,要咬 20 口)歸零塌成廢墟,站回地基花 $100 修復。數值在 `data/config/game.json` 的 `tower`。
- 音效是程式合成的占位版(`tools/gen_sfx.py` 產生 `assets/sfx/*.wav`),之後拿正式音檔同名覆蓋即可。
- 守衛塔升級:走到完好的塔旁邊,畫面下方出現「升級」鈕,按了開面板;射速與傷害各可升 10 次、每次 $500(射速每級射擊間隔 ×0.92,傷害每級 +20%)。
- 衛兵:第四次擴建後南塊有「僱用衛兵」牌 $300(可僱 4 位),穿盔甲拿斧頭、頭上標「衛兵」,在村裡巡邏,看到北極熊或熊王就衝上去打,不會被嚇呆、但會被吃。熊王等級上限 Lv5。
- 價格牌:站上去 0.6 秒後開始付,$25 以上的牌約 1.25 秒付清。
- 往南擴建到第七次:$16000(切魚台 ×2 + 烤魚攤)、$32000(烤魚攤 ×2 + 廚房)、$64000(廚房 ×2),每塊都有兩座守衛塔、捕熊夾、誘餌、傳送帶牌與自己的顧客門,
  僱用名額每次再開一輪(漁夫一開始 5 位、每次 +3)。
- 雪地貨車:主村南排「雪地貨車」牌 $1500(最多 3 台),漁夫開車出村到南邊雪原的三座魚池,每趟撈 30 條回來卸在「貨物放置區」(最多 300 條);
  搬運工會去放置區拿魚送到切魚台。玩家也可以自己走去魚池抓魚。
- 故事(長冬與冰母):教學、北極熊、訂單、地圖、南邊擴建、三片地圖拼齊各解鎖一章短文;武器店老闆 / 船長 / 旅行商人 / 修理工站旁邊一秒會說話,
  顧客偶爾說自己聚落的事;雪原的岩石 / 枯樹 / 雪堆走近留下線索;選單「日誌」頁可重看。三片地圖拼齊後雪原東北角出現「冰母的神龕」,
  放回 3 條稀有魚是結局——然後遊戲照常繼續。大綱在 notes/story_outline.md。
- 部署 / 雲端:原始碼與網頁成品同在 GitHub `tyboy0407/manlife-play`(成品在 `docs/`,Pages 從那裡發布);
  `python tools/deploy_web.py` 匯出並推上去。Linux / claude.ai/code 雲端環境先 `bash tools/setup_cloud.sh` 裝 Godot,測試用 `bash tools/run_tests.sh`。
- 數值:`data/config/game.json`(速度、容量、搬運 / 收錢 / 付錢速率與付錢前停留秒數、魚群、顧客、幫手、升級、自動存檔);物品 `data/items.json`;站點 `data/stations.json`;櫃台 `data/counters.json`;價格牌 `data/shop.json`;文字 `data/locale/strings.csv`。
- 跑測試:`powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1`
